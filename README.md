# The Filo Freelance Club website (draft)

Initial draft of the website, built from the website map: Home, Self-Assessment, Learning Hub and Contact.

- Plain HTML, CSS and JavaScript. No build step: open `index.html` or serve the folder.
- All content (guides, career paths, assessment questions and scoring, social links) lives in `assets/js/data.js`.
- Brand palette: blue `#1437a2`, yellow `#f0b941`, cream `#f8f7f3`.

Not connected yet (needs a backend): emailing assessment results to Miggy, CV uploads, the contact form, and the CMS / admin dashboard.

Run locally: `python3 -m http.server 3400` then open http://localhost:3400
